## Upload to the existing GitHub Pages site

1. Open https://github.com/engrmjdc/mackjohn-portfolio.
2. Use Add file > Upload files on the branch configured for Pages.
3. Upload index.html, styles.css, script.js, and the assets folder, retaining these paths.
4. Commit the changes and allow the existing Pages deployment to finish.
5. Refresh the website and check the resume download.

No build tools or new hosting are required. The .nojekyll file can remain in the repository.
This delivery has not been pushed to GitHub or published.

## Local preview

Serve the folder with any static HTTP server, or open index.html directly.
